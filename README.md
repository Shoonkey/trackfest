A tool for tracking vehicle piece sets from the game [The Crew: Motorfest](https://en.wikipedia.org/wiki/The_Crew_Motorfest).

Built using [Tauri](https://v2.tauri.app/) and [Preact](https://preactjs.com/).

### Features

The tool will allow for tracking pieces from every vehicle type and piece set in the game, which currently are:

#### Vehicle types

- Street Tier 1
- Street Tier 2
- Drift
- Racing
- Dragster
- Hypercar
- Alpha GP
- Motocross
- Rally
- Rally Raid
- Demolition
- Monster
- Powerboat
- Plane

#### Piece sets

- Nitro Chemist
- Scorebreaker
- Loot Digger
- Treasure Sniffer
- XP Magnet
- Bucks Magnet
